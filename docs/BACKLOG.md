# BACKLOG — идеи из анализа проекта, в работу пока не берутся

Здесь лежат пункты, которые не вошли в текущую итерацию. Порядок примерно по
убыванию ценности. Перед взятием в работу — обсудить и, если нужно, внести в
`docs/SPEC.md` явным решением владельца.

## Поведение

1. **Поддержка других видов туннелей.** Добавить IP-IP и GRE наряду с
   WireGuard/AmneziaWG.
2. **Компактный QR-код в терминале.** Текущий вывод Unicode half-block занимает
   слишком много места. Рассмотреть Unicode Braille (2×4 модуля на символ) для
   уменьшения ширины и высоты примерно вдвое без отбрасывания модулей. Проверить
   поддержку шрифтами и надёжность сканирования в целевых терминалах. Перед
   реализацией явным решением владельца обновить SPEC 6.5, который требует half-block.

## Распространение и обновления

1. **Репозитории пакетов для корректного обновления.** Настроить публикацию
   подписанных APT- и DNF/YUM-репозиториев для `.deb` и `.rpm` (`amd64`/`arm64`),
   чтобы обновления выполнялись штатно через `apt` и `dnf`, без ручной загрузки
   пакетов релизов.
